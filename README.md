# Example Astro Site

A simple Astro example site, ready to deploy.

## Setup

```bash
npm install
npm run dev
```

## Deploy with Ink

Connect the [Ink MCP server](https://docs.deployink.com/quick-start) to your AI agent and prompt:

> Deploy this Astro site with Ink.
